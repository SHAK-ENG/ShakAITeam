# Task type: ad-video
Deliverable: concept → timed storyboard → rendered video (if a video skill/tool is available) or production-ready storyboard + asset list.
Default complexity: C2 (C4 if it's a launch or brand-defining ad).

| Parameter | Required | Default | Infer from |
|---|---|---|---|
| Product / main character | yes | — | message, entity |
| Goal | yes | installs | entity defaults |
| Reference video (style to learn) | no | none | attachments |
| Platform & aspect | yes | Instagram Reels / TikTok 9:16 | entity defaults |
| Length | yes | 30 s | entity defaults, platform |
| Style | yes | motion graphics | reference video, entity |
| Language(s) | yes | entity default language | entity |
| Voiceover | yes | yes, natural voice | entity learnings |
| Key message / feature to show | yes | entity's top USP | entity profile |
| CTA | no | "Download now" + store badges | entity |
| Music mood | no | upbeat, modern | reference, entity |
| Must avoid | no | entity "don't" list | learnings |

Acceptance criteria (base):
1. Product is visible/named within the first 2 s; hook in first 3 s.
2. Length within ±2 s of target; aspect ratio correct.
3. On-screen text ≤7 words per card, readable on mobile.
4. Brand colors/fonts used; nothing from the "don't" list.
5. Clear CTA in the last 3–5 s.
6. If a reference was given: structure is learned (pacing, hook type, CTA timing), content is original.

Ask first (if unknown): platform & aspect, length, style, voiceover/language.
