# Task type: research
Deliverable: `research/<slug>.md` — summary, findings table, sources, confidence.
Default complexity: C2; C3 if sources conflict or numbers must be estimated.

| Parameter | Required | Default | Infer from |
|---|---|---|---|
| The decision this research informs | yes | — | message |
| Question(s) | yes | — | message |
| Scope (markets, time range, competitors) | no | global, last 2 years | entity |
| Depth / source budget | no | Draft 3, Balanced 6, Polished 12 sources | polish |
| Output format | no | ≤1 page summary + table | — |

Acceptance criteria (base):
1. Directly answers the question tied to the decision.
2. Every number has a source + date; inferences labelled.
3. Confidence level and open questions stated.

Ask first (if unknown): what decision this informs, scope.
