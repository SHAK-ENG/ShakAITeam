# Task type: campaign
Deliverable: plan doc (`marketing/<slug>.md`) + first batch of copy/assets.
Default complexity: C2; C3 for multi-channel launches.

| Parameter | Required | Default | Infer from |
|---|---|---|---|
| Product / main character | yes | — | message, entity |
| Objective & KPI | yes | installs / signups | entity defaults |
| Audience segment | yes | entity audience | entity |
| Channels | yes | entity default channels | entity history |
| Budget | no | organic / $0 | message |
| Timeline | yes | 4 weeks | message |
| Markets / languages | no | entity default | entity |
| Offer / hook | no | entity top USP | entity |

Acceptance criteria (base):
1. One core message; audience, channel, KPI and timeline explicit.
2. Week-by-week calendar with owners (roles).
3. At least 3 cheap experiments with success thresholds.
4. First batch of copy delivered in brand voice.

Ask first (if unknown): objective/KPI, channels, timeline, budget.
