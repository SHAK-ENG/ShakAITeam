# Task types (pick one; read only that file)
- ad-video — short ad / promo / social video, optionally learning from a reference video
- landing-page — website page or section: copy + design + build
- feature — new software capability in an existing codebase
- bug-fix — something broken, an error, a failing test or build
- campaign — marketing/GTM plan, launch, content calendar, SEO plan, social posts series
- research — market, competitor, tech or literature question needing sources
- plan — roadmap, sprint plan, project plan, status update, meeting notes
- docs — README, guide, API docs, changelog, CLAUDE.md
- generic — anything else

To add a task type: copy `generic.md`, rename, fill the parameter table, add one line here.
